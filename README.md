# Customer Behavior & Business Insights

An end-to-end data analytics project using **Python, SQL, MySQL, and Power BI** to explore customer shopping patterns, purchasing behavior, subscription trends, discount usage, and customer satisfaction.

## Project Overview

Understanding customer behavior helps businesses identify purchasing patterns, evaluate customer engagement, and make better data-driven decisions. This project analyzes customer shopping data and presents key findings through SQL queries, Python-based analysis, and an interactive Power BI dashboard.

## Project Objectives

- Analyze purchasing behavior across product categories and seasons.
- Understand customer segments by age and gender.
- Compare purchasing patterns of subscribers and non-subscribers.
- Examine discount usage and payment method preferences.
- Evaluate customer satisfaction using review ratings.
- Present business insights through an interactive dashboard.

## Dataset

The project uses customer shopping behavior data containing customer demographics, purchased products, transaction amounts, ratings, subscription status, discounts, shipping types, and payment methods.

**Key attributes include:**
- Customer ID, Age, Gender, Age Group
- Item Purchased, Category, Purchase Amount
- Location, Size, Color, Season
- Review Rating, Subscription Status
- Discount Applied, Promo Code Used
- Previous Purchases, Payment Method
- Frequency of Purchases

## Project Workflow

1. **Data preparation:** Inspect and clean the customer shopping dataset using Python.
2. **SQL analysis:** Query the data to answer business questions and summarize customer behavior.
3. **KPI development:** Calculate customer count, average purchase amount, average review rating, subscription rate, and discount usage rate.
4. **Power BI visualization:** Build an interactive dashboard with slicers and multiple chart types.
5. **Business insights:** Explore differences across categories, products, seasons, customer segments, and payment methods.

## Power BI Dashboard

The dashboard provides an overview of customer behavior and business performance through:

### Key Performance Indicators
- Number of Customers
- Average Purchase Amount
- Average Review Rating
- Subscription Rate
- Discount Usage Rate

### Visual Analysis
- Total Purchase Amount by Category
- Purchase Amount by Product
- Customer Satisfaction by Category
- Purchase Amount by Season
- Customer Count by Payment Method
- Sales by Age Group

### Interactive Filters
Users can filter the report by category, subscription status, shipping type, season, and gender to explore different customer segments.

## How to Explore the Project

1. Clone or download this repository.
2. Open the Jupyter Notebook to explore the Python analysis.
3. Import the dataset into MySQL and run the SQL queries using MySQL Workbench.
4. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
5. Use the available slicers to analyze different customer segments.

**Requirements:** Python, Jupyter Notebook, MySQL Server, MySQL Workbench, and Power BI Desktop.
